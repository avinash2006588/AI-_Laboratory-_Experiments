## How to Run the Programs

First clone the repository using the following command

```bash
git clone https://github.com/avinash2006588/AI-_Laboratory-_Experiments.git
```

Open the project folder

```bash
cd AI-_Laboratory-_Experiments
```

Run a Python program

```bash
python filename.py
```

Replace filename.py with the name of the Python file you want to execute.

If the experiments are in Jupyter Notebook format install Jupyter Notebook

```bash
pip install notebook
```

Start Jupyter Notebook

```bash
jupyter notebook
```

Open the required notebook and execute the cells.
